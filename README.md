E-Commerce Online Shopping System
Java | Spring Boot | MySQL | Maven
This project is a complete backend system for an online shopping application.
It includes user authentication, product management, shopping cart, and order processing features.

🚀 Features

👤 User Module
User Registration
User Login
Password Encryption

📦 Product Module
View Products
Add Products
Update Products
Delete Products

🛍️ Cart Module
Add to Cart
Remove from Cart
Update Quantity
View Cart

🧾 Order Module
Create Order
View Order Summary
Order History

🛠️ Technologies Used
Java
Spring Boot
Spring Data JPA
MySQL
Maven

schema.sql

▶️ How to Run the Project
1️⃣ Install Required Tools
JDK 17+ (or your version 24 is also fine)
Maven
MySQL

2️⃣ Configure Database
Update MySQL username & password in:
src/main/resources/application.properties

3️⃣ Run Backend
Use:
mvn spring-boot:run
or
run the main class:
EcommerceApplication.java
